### [UCMS — University Club Management System](https://github.com/gyangho/UCMS)

A full-stack web platform developed to automate university club operations, including recruitment, interview scheduling, settlements, events, and POS management.

- Designed, developed, deployed, and operated the service independently.

- Reduced recruitment administration time by approximately **60%**.

`Node.js` `Express` `MySQL` `Docker` `NGINX`

### [뽀송길 — Weather-Aware Route Planning](https://github.com/gyangho/pposonggil_v2)

A public transit route planner that incorporates weather data to minimize rain exposure during walking segments.

- Customized the **OSRM routing engine** with weather-aware route weights.
- Integrated public transit and weather forecast APIs.
- Implemented OAuth2/OIDC authentication and containerized deployment.
- Awarded **Silver Prize** at the Soongsil Capstone Design Competition.
- Related published patent application: **10-2026-0018526**.

`Spring Boot` `React` `OSRM` `MySQL` `Docker`

### [SimplePoW — Distributed Proof of Work](https://github.com/gyangho/SimplePow)

A distributed Proof-of-Work computation system using Linux processes and network communication.

- Designed communication protocols between main and worker servers.
- Implemented parallel SHA-256 computations and asynchronous I/O using epoll.
- Reduced computation time from **1,028s to 66s** in a benchmark scenario.

`C` `Linux` `epoll` `OpenSSL`

### [FootPrint — Real-Time Game Minimap](https://github.com/gyangho/FootPrint)

A real-time multiplayer minimap developed through game network packet analysis.

- Captured and analyzed UDP packets using Wireshark and WinPcap.
- Extracted player coordinates through packet parsing and reverse engineering.
- Visualized player positions in Unity.

`C` `WinPcap` `UDP` `Unity` `C#`
